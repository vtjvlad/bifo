# План миграции с Bootstrap на кастомные стили

## Текущее состояние
- Bootstrap 5.3.0 подключен через CDN
- Используется в 5 HTML страницах
- Активно используются компоненты: кнопки, сетка, модальные окна, карточки

## Этапы миграции

### Этап 1: Подготовка (1-2 дня)
- [ ] Создать кастомную CSS систему
- [ ] Определить цветовую палитру и переменные
- [ ] Создать базовые компоненты (кнопки, сетка, формы)
- [ ] Настроить адаптивность

### Этап 2: Постепенная замена (3-5 дней)
- [ ] Заменить кнопки (btn классы)
- [ ] Заменить сетку (container, row, col)
- [ ] Заменить карточки (card компоненты)
- [ ] Заменить формы (form-control, form-group)

### Этап 3: Сложные компоненты (2-3 дня)
- [ ] Переписать модальные окна
- [ ] Переписать dropdown меню
- [ ] Переписать навигацию
- [ ] Переписать пагинацию

### Этап 4: Тестирование и оптимизация (1-2 дня)
- [ ] Тестирование на всех устройствах
- [ ] Оптимизация производительности
- [ ] Удаление Bootstrap файлов

## Альтернативные CSS-фреймворки

### Tailwind CSS
**Преимущества:**
- Utility-first подход
- Очень гибкий
- Отличная документация
- Активное сообщество

**Недостатки:**
- Крутая кривая обучения
- Большой размер в production

### Bulma
**Преимущества:**
- Современный и легкий
- Простой в использовании
- Хорошая документация

**Недостатки:**
- Меньше компонентов чем Bootstrap
- Меньше сообщество

### Foundation
**Преимущества:**
- Профессиональный
- Много готовых компонентов
- Хорошая адаптивность

**Недостатки:**
- Сложнее чем Bootstrap
- Больше размер

## Рекомендация

**Для вашего проекта рекомендую:**

1. **Начать с кастомных стилей** - у вас уже есть хорошая база в `base.css`
2. **Постепенно заменить Bootstrap** - компонент за компонентом
3. **Сохранить адаптивность** - использовать CSS Grid и Flexbox
4. **Оптимизировать размер** - убрать неиспользуемые стили

## Примеры замены

### Кнопки
```css
/* Вместо Bootstrap btn классов */
.btn {
    display: inline-block;
    padding: 0.5rem 1rem;
    border: none;
    border-radius: 0.25rem;
    text-decoration: none;
    cursor: pointer;
    transition: all 0.3s ease;
}

.btn-primary {
    background-color: var(--primary-color);
    color: white;
}

.btn-primary:hover {
    background-color: var(--primary-dark);
    transform: translateY(-1px);
}
```

### Сетка
```css
/* Вместо Bootstrap grid */
.grid {
    display: grid;
    gap: 1rem;
}

.grid-2 { grid-template-columns: repeat(2, 1fr); }
.grid-3 { grid-template-columns: repeat(3, 1fr); }
.grid-4 { grid-template-columns: repeat(4, 1fr); }

@media (max-width: 768px) {
    .grid-2, .grid-3, .grid-4 {
        grid-template-columns: 1fr;
    }
}
```

## Временные рамки
- **Полная миграция**: 7-10 дней
- **Поэтапная миграция**: 2-3 недели
- **Тестирование**: 2-3 дня

## Риски
- Временная потеря функциональности
- Потенциальные баги в кастомных компонентах
- Необходимость переобучения команды
