# CSS Структура проекта Купи слона

Этот проект использует модульную структуру CSS файлов для оптимизации загрузки и поддержки кода.

## Структура файлов

### 1. `base.css` - Базовые стили
**Используется на всех страницах**

Содержит:
- CSS переменные (цвета, шрифты)
- Глобальные стили для body
- Стили навигации (navbar)
- Базовые стили кнопок
- Стили форм и полей ввода
- Стили модальных окон
- Утилитарные классы
- Анимации
- Адаптивный дизайн (общие правила)

### 2. `home.css` - Стили главной страницы
**Используется на: `index.html`**

Содержит:
- Hero section с градиентным фоном
- Стили поисковой формы
- Анимации для hero section
- Стили карточек категорий
- Адаптивный дизайн для главной страницы

### 3. `category.css` - Стили страницы категории
**Используется на: `category.html`**

Содержит:
- Стили страницы категории (фон, контейнер)
- Улучшенные breadcrumbs
- Стили боковой панели фильтров
- Стили карточек продуктов
- Стили списка продуктов
- Стили пагинации
- Стили аккордеона фильтров
- Адаптивный дизайн для страницы категории

### 4. `product.css` - Стили страницы товара
**Используется на: `product.html`**

Содержит:
- Стили страницы товара (фон, контейнер)
- Стили секции изображений товара
- Стили информации о товаре
- Стили цен и скидок
- Стили вкладок (характеристики, описание, отзывы, предложения)
- Стили предложений от разных продавцов
- Стили похожих товаров
- Адаптивный дизайн для страницы товара

### 5. `catalog.css` - Стили страниц каталогов
**Используется на: `catalog.html`, `catalog-cache.html`**

Содержит:
- Стили карточек каталогов
- Стили аккордеона для структуры каталогов
- Стили ссылок на категории
- Стили управления кэшем
- Стили статистики кэша
- Стили уведомлений
- Адаптивный дизайн для страниц каталогов

## Принципы организации

### 1. Модульность
Каждый CSS файл отвечает за конкретную функциональность и используется только на соответствующих страницах.

### 2. Базовые стили
`base.css` содержит все общие стили, которые используются на всех страницах.

### 3. Специфичные стили
Каждая страница имеет свой CSS файл с уникальными стилями.

### 4. Производительность
- Загружаются только необходимые стили для каждой страницы
- Уменьшается размер загружаемых файлов
- Улучшается время загрузки страниц

## Использование

### Для добавления новых стилей:

1. **Общие стили** - добавляйте в `base.css`
2. **Стили для конкретной страницы** - добавляйте в соответствующий файл
3. **Новая страница** - создайте новый CSS файл и подключите его в HTML

### Пример подключения в HTML:

```html
<!-- Базовые стили (всегда) -->
<link rel="stylesheet" href="css/base.css">

<!-- Специфичные стили (только для нужной страницы) -->
<link rel="stylesheet" href="css/home.css">
<link rel="stylesheet" href="css/category.css">
<link rel="stylesheet" href="css/product.css">
<link rel="stylesheet" href="css/catalog.css">
```

## Переменные CSS

Все цвета и основные значения определены в `base.css`:

```css
:root {
    --primary-color: #ffc107;
    --secondary-color: #343a40;
    --accent-color: #dc3545;
    --text-dark: #212529;
    --text-light: #6c757d;
    --bg-light: #f8f9fa;
    --border-color: #dee2e6;
}
```

## Адаптивный дизайн

Каждый CSS файл содержит медиа-запросы для адаптации под разные размеры экранов:
- `@media (max-width: 768px)` - планшеты
- `@media (max-width: 576px)` - мобильные устройства

## Анимации

Общие анимации определены в `base.css`:
- `fadeIn` - появление элемента
- `slideInLeft` - появление слева
- `slideInRight` - появление справа
- `fadeInUp` - появление снизу

Специфичные анимации для каждой страницы определены в соответствующих файлах.
